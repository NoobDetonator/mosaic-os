# Telas e monitores

Um computador do Minecraft tem uma tela pequena. Mas ele pode mandar um
programa para um **monitor** - aquela parede de blocos - e usar a parede
inteira.

Isso resolve um problema chato: antes, para ter tres coisas aparecendo em
tres paredes, voce precisava de tres computadores. Agora e um so.

## Mandando um app para a parede

Clique com o **botao direito** no botao do app na barra de tarefas. Aparece
um menu com os monitores conectados e o tamanho de cada um:

```
Para 0 (60x20)
Para 1 (30x10)
```

Escolha um e o app muda de casa. Ele some da area de trabalho e aparece na
parede, ocupando tudo.

Na barra de tarefas o nome dele ganha o numero do monitor na frente
(`0:Reator`), para voce nao perder o programa de vista.

Para trazer de volta, mesmo menu: **Trazer de volta**.

## O que muda quando o app esta na parede

**O tamanho.** O app se re-ajusta sozinho ao tamanho do monitor. Um painel
que mostrava dois graficos na janela pode mostrar seis na parede.

**O clique.** Monitor avancado responde a clique de **botao direito** do
jogador. Isso funciona, e o app recebe como um clique normal.

**Arrastar nao existe.** O Minecraft nao avisa quando voce arrasta o dedo
num monitor, so quando clica. Por isso um monitor mostra **um app inteiro**,
e nao varias janelas: janela que nao se arrasta seria pior que nao ter.

**Teclado nao existe.** Monitor nao manda tecla. Se o app precisa de
digitacao, digite no computador - o teclado continua indo para a janela
que estiver em foco la.

E de proposito: **tocar na parede nao rouba o foco do teclado**. Voce pode
estar escrevendo uma nota no computador enquanto alguem aperta um botao na
parede, e as letras continuam indo para a nota.

## Um app por monitor

Cada monitor segura um app. Se voce mandar um segundo app para o mesmo
monitor, o primeiro volta para a area de trabalho - ninguem some.

## Se o monitor quebrar

Se alguem quebrar o bloco com o computador ligado, o app volta sozinho para
a area de trabalho e um aviso aparece. Ele nao trava tentando escrever num
monitor que nao existe mais.

## Escala do texto

O Mosaic escolhe sozinho. A regra: se der para caber muita coluna com o
texto pequeno, ele usa o pequeno (mais informacao na parede); senao usa o
**maior** texto que ainda couber, porque ler de longe vale mais do que
espremer.
